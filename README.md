# 決める前に、一つの作業を終える

駐車場を貸せる時間、処分の期日、見積方法の実測を整理する無料ツールです。自分で確認した予定や計測値から、結果と残る確認をTXT・CSVで持ち帰れます。必要な作業を一つ選んでください。

## 家族の車と、貸せる時間が重ならないか確かめる

[曜日別の駐車時間を整理する](https://tomoka-uzumaki-ai.github.io/qualified-task-decisions-jp/parking-windows/)

貸せる予定時間と、家族・自分が使う時間を入力します。重ならない候補時間と週の合計を一覧にし、確認票とCSVを保存できます。家族の利用を未確認のまま「なし」にせず、貸出の権限や物件の制限も確認してください。

実際の登録を検討する場合だけ、[貸出条件と料金の確認](https://parking-host-days-check.pages.dev/)へ進めます。候補時間は予約や需要を示すものではなく、収益の保証でもありません。貸出を始めず、予定の整理だけで終えても構いません。

## 退去・引渡しまでに、処分できる日程を整理する

[処分の期日と、確認した最短日を比べる](https://tomoka-uzumaki-ai.github.io/qualified-task-decisions-jp/disposal-deadline/)

自治体、家電リサイクル、民間回収の窓口で自分が確認した最短日を入力します。期限内に残る候補、過去・期限後の日程、未確認の窓口を分け、確認票とCSVを保存できます。品目の対象や空きを検索・予約する機能ではありません。

対象品や搬出条件、見積総額をさらに比べる場合は、[処分の料金・対象品と回収条件](https://moveout-disposal-check.pages.dev/)を確認できます。自治体などで完了できれば、民間サービスへの申込みは不要です。日程の入力だけでは、処分の許可や予約は確定しません。

## 見積方法を変える前に、同じ3件で実測を比べる

[同じ3案件の作業時間と追加費用を比較する](https://tomoka-uzumaki-ai.github.io/qualified-task-decisions-jp/quote-time-trial/)

現在の方法と候補の方法を、自分で同じ範囲まで計って秒数を入力します。3件の平均差だけでなく、遅くなった案件と追加月額も分けて確認し、結果をTXT・CSVで保存できます。月の同等案件数による時間差は仮定の計算です。

不足する機能や費用を検討する場合だけ、[見積方法の機能・費用の確認](https://quote-revision-check.pages.dev/)へ進めます。追加費用が不明なら回収できるとは判断しません。今の方法や表計算で足りる場合は移行不要です。3件の結果は将来の性能や利益を保証しません。

## 保存・利用条件と広告について

ブラウザーとJavaScriptを使います。入力は端末内で処理し、外部送信・保存しません。名前・住所・顧客情報・口座番号は入力せず、ページを閉じる前に必要な結果を自分で保存してください。入力値の真正性を認証するものではありません。

上記の無料作業に、申込み・契約・支払いは不要です。その後の条件確認ページにはアフィリエイト広告が含まれます。紹介先への申込み等が所定の条件を満たすと、運営者が紹介料を受け取る場合があります。リンクを開くだけで予約・契約・送信を実行することはありません。外部サービスを利用する場合は、対象・総額・契約と解約の条件を購入前の公式画面で確認してください。
